# Put the raw data here

This folder is ignored by Git on purpose: the raw Kaggle files are not stored in the repository.
Download them yourself (free Kaggle account) and place them here with these exact names:

| File | Kaggle dataset | Notes |
|---|---|---|
| `upwork-jobs.csv` | [Upwork Job Postings Dataset 2024 (50K Records) by asaniczka](https://www.kaggle.com/datasets/asaniczka/upwork-job-postings-dataset-2024-50k-records) | 53,058 rows, 9 columns |
| `Resume.csv` | [Resume Dataset by Snehaan Bhawal](https://www.kaggle.com/datasets/snehaanbhawal/resume-dataset) | inside the zip at `Resume/Resume.csv`; 2,484 rows |

Then run `python -m giglink_ai.experiments` from the repository root.
